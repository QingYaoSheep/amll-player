## 实现

- 每个原生沉浸呈现实例只分配一次有序身份。新实例接管共享帧容器及接收层后，旧实例不可重新接管。
- 视频帧来源同时关联呈现实例及资源代次。相同资源的更新、暂停、循环与取帧备用输出不重建来源；实际资源替换才重建。
- 取帧、输出诊断、回调、布局诊断与清理校验当前会话。旧视图只清理自己的播放器、图层和任务，不清空新会话。
- 保留最近接受的不可变像素帧，暂停及接收层重新挂载可以重放。没有取消来源拒绝保护。
- 分别统计取得、接受、拒绝与提交；备用取帧只针对解码无像素，播放器级的已提交时间只在接受后推进。
