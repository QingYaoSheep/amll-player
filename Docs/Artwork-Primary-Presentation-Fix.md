## 修改

- 主视频首帧、播放状态及失败回调只校验当前呈现实例与资源，辅助像素帧仍严格校验自己的来源代次。倒影失效不再挡住主视频的显示回调。
- 仅当前呈现实例的显式配置可以恢复失效绑定；采样过程不抢占来源，旧视图无法复活或清空新画面。
- 恢复绑定时重置解码等待计时及播放器级输出的同帧去重，保留原 AVPlayer、AVPlayerItem、取帧输出与播放/暂停状态。
- 生产者最多保留一份已接受像素帧。暂停时重新绑定可以重放它，避免向不保证重复输出暂停像素的 item 输出索取新帧；资源替换、停止及清理释放此引用。
- 诊断直接包含内嵌构建号、播放器实例、主视频首帧及当前绑定是否有效。绑定状态按实际来源计算，暂停失效也立即可见；更换/释放呈现时清理主视频诊断。
- 增加 item 输出失效超过一秒后的恢复回归，确认接收者等待不会触发解码备用切换。

保留现有沉浸布局、倒影几何与亮度、视频渐隐、过渡模糊及动态背景自身模糊。不恢复已回退的 GPU 合成重写，不创建第二个播放器。iPhone 显示歌词时的静态封面规则保持原状。

## 设备验收

安装当前代码对应 IPA 后，检查隐藏歌词时有竖版资源的沉浸视频是否显示并运动，倒影是否出现并同步运动；暂停、切歌、缓存替换及再次显示页面后应继续正确。若未通过，复制新版诊断首行构建号及后续数据，避免将旧日志归到新包。音乐不中断与视觉结果必须另行确认。
