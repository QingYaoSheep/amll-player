## 2026-09-25 逐词音译接线修正

- 来源词音译保留为单一容器及原词归属，嵌入空格不再导致注音丢失；相邻拉丁音节仍保持同一断行/强调 chunk。
- 独立音译时间通过 romanStart/romanEnd 兼容保存，布局遮罩直接消费；相同时复用正文时间。解析版本升至 5，旧原始载荷可重解析。
- TTML 与辅助资源使用统一互唯一匹配，拒绝并列、跨多词整行注音及声部不明的行匹配，不覆盖已有明确音译。
- 原版浏览器 7 组多语言夹具实测通过：半字号、1em 行高、0.3em 末端留白、缺词占位。原生修正无 ruby 的 start 对齐、紧凑行高和重复降低 alpha；ruby 容器继续居中。
- 主动差异：原版分词会复制内部含空格词的整段 romanWord，本实现按用户要求只保留一份，不生成分词注音时间。
- 新增 Swift 来源/时间/缓存兼容/多声部/Unicode/开关回归；本地 SwiftFormat 和 12 项 Node 回归通过，新增 Swift 用例等待 Xcode 27。原版探针命令：AMLL_ROMANIZATION_PROBE=1 node Scripts/check-amll-controlled-browser.cjs（PowerShell 使用环境变量赋值）。
- 仍待验证：同 Apple 字体基线、HDR/SDR 合成真机显示、完整暂停/seek/回收动画图像对照及 VoiceOver 实机阅读；不能据此宣布逐字音译已完整视觉验收。

## 2026-09-19 动态封面不再等待后台缓存

- 修正静默 discretionary 下载可能长期排队、页面又必须等待本地文件导致一直“加载中”的设计问题：允许网络下先使用 HTTPS AVURLAsset 无声播放，静默缓存独立等待，成功后切换本地资源。
- AVURLAsset 显式限制蜂窝、昂贵网络及低数据模式；远程视频在页面暂停时释放，切歌/网络策略变化清除旧资源。继续禁用音轨，不创建新的音乐播放后端。
- HLS 缓存等待上限 120 秒，超时取消且不阻塞在线封面。播放仍依赖实际资源可访问和设备解码；未做设备签收。
- 新增缓存完成前即可取得播放 URL、缓存超时不撤销在线播放及成功切换本地的回归源码。Windows 只完成格式/diff 检查，Swift 测试由 Actions 执行。
