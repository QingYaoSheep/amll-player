# 流动背景

## 已批准行为

- 独立背景模式 `flowing`，显示名“流动背景”，不替换 Mesh/Pixi，不自动切换已有选择。
- 一张原始静态封面自动放大铺满视口，顺时针旋转、柔和波浪扭曲，**变换之后**进行 MPS 高斯模糊，不额外调色。纹理和输出保持 SDR，页面暗度及文字合成层级不变。
- 默认旋转 1.5°/秒、扭曲最大位移为视口短边的 3%、高斯 sigma 40pt。设置范围分别为 0–6（步进 0.25）、0–8%（步进 0.5）、0–80pt（步进 5）。局部重置仅恢复这三个值。
- 两组波浪周期为 18/27 秒；最大组合位移受强度约束。放大尺寸覆盖视口对角线，并预留最大 8% 的扭曲余量。模糊转换为实际输出像素 sigma，边缘钳制；零模糊绕过滤镜。
- 背景使用独立 60Hz 调度及真实经过时间，暂停歌曲仍流动；隐藏、切换模式和后台停止时钟与 GPU 提交，恢复不追赶离开期间的时间。速度调整不重置角度，强度/模糊使用 0.3 秒缓动。
- 新封面准备后 1 秒渐变，运动相位不重置；中断渐变使用当前变换后、模糊前的合成快照，以视口坐标采样，不再次扭曲快照。
- 远程/系统本地封面共用既有加载入口，后台串行解码，按请求代次拒绝旧结果；错误不在每次输入更新中无限重试。页面重新激活可重新请求失败资源。
- 资源与 GPU 在途槽位有界，最多两个提交。GPU 不可用时采用后台 Core Image 静态模糊回退。减少动态效果时静止；减少透明度时显示既有不透明底色。

## Standards

- 未发现已记录代码规范的硬性违反或需处理的代码气味。
- 初轮发现两个生命周期问题：静态回退任务隐藏时取消后未恢复；减少动态效果的单次绘制在两个 GPU 槽位占用时未重试。`99b29268` 已补可见性恢复和 GPU 完成回调，追加回归，两次规范复核确认修复。

## Spec

- 初轮发现三项计划缺口：被取消的静态模糊结果未恢复、静帧 GPU 错误需等待下一帧才回退、纹理/编码器分配失败没有进入静态回退。`99b29268` 已分别闭合；无额外范围扩展。
- 正常未取得 drawable 或在途槽位占满保持可重试，不误判 GPU 失败；真实渲染失败立即切到后台 Core Image 回退。测试通过共享事件明确阻塞两个在途槽位，验证完成通知及释放后可再次提交。

审查合计：Standards 2 项、Spec 3 项，均已解决；Apple 执行证据与设备验收状态分开记录。

## 待设备验收

在 iPhone 16 Pro 和 13 英寸 iPad Pro 上，记录系统、安装包提交、显示缩放、温度及 HDR 余量，连续 15 分钟覆盖播放/暂停、快速切歌、横竖屏/分屏、隐藏/恢复、减少动态效果和减少透明度。

- 参数：先默认值，再零模糊/零扭曲及最大参数；检查四边覆盖、配色与调整连续性。
- 合成：歌词显示/隐藏、沉浸封面、全屏/拖动缩小；检查 HDR/Plus Lighter 与旧歌词动效。
- 性能：使用 Instruments GPU/Time Profiler 与可注入的有界背景采样接口，记录 CPU/GPU P50/P95/P99、实际帧间隔、最长帧和纹理占用；同时查看歌词 60/120Hz 是否受到阻塞。模拟器小纹理测试的短时数字不用于推断设备表现。
