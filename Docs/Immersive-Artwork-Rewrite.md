# 沉浸封面与播放页重写

实施基线：`84bd2602145359e8c651926ac4bed202d9a5d1fb`。本轮只更改沉浸封面合成、手机隐藏歌词时的排版与临时校准入口。已有歌词回放工作区修改保留。

## 固定验收契约

1. 竖版视频顶部居中、等比完整显示，不裁剪。iPhone 竖屏隐藏歌词采用新排版，iPad 保留双栏。
2. 合成顺序固定：所选背景及背景暗度 → 完整视频及旧渐隐 → 同帧镜像倒影及独立向下淡出 → 全画面渐变模糊 → 清晰信息和控件。
3. 视频渐隐复用 `AMLLImmersiveArtworkGeometry.videoFadeStops`：上方 66% 不透明，底部 34% 按原采样及线性插值降至透明。只作用于视频；启用倒影仍保留，减少透明度时不用此遮罩。
4. 倒影来自完整视频的真实垂直镜像，不拉伸底部条带。长度默认占据剩余屏幕、上限为视频高度；保留原开关。
5. 渐变改变实际高斯模糊半径，不改变合成图透明度。信息区上方 96pt 开始，144pt 内达到 32pt，之后保持到屏幕底边。背景不重复模糊，暗度只处理背景。
6. 单播放器、单视频帧、单 60Hz 显示调度器；Core Image/Metal 直接输出纹理，不截取 UIKit 层树或逐帧回传 CGImage。最多两个提交在途，过期输入合并。
7. 暂停保留最后有效帧，背景按原规则运行。只有统一画面完成提交才报告首帧；沿用有界首帧/缓冲等待和取帧备用输出。切歌、循环、旋转、后台及关闭校验代次并释放资源，失败整体回退。
8. 集中音频策略保留，不新增播放器或歌曲级系统控制；歌词引擎、HDR、音译、焦点、seek 和真实时间不改。

## 手机布局和校准

参考 402×874pt、底部安全区 34pt：横向留白 32pt，信息顶部 497pt，进度中心 574pt，播放中心 666pt，音量中心 756pt，底部操作中心 813pt。控制位置按视口和安全区计算，不保留方形封面占位，也不随视频比例移动。小屏压缩间距，大字体空间不足时允许控制区滚动。

临时校准仅保留模糊起点/范围/半径、倒影长度/不透明度、固定旧渐隐开关，支持恢复和导出。新参数使用独立 `AMLL.immersiveArtworkStyle.v2`；旧层序/几何调试数据原样保留，生产路径停用。

## 首次设备反馈与阻塞修复

`a05662c5` 直接包设备反馈为“加载到动态封面直接卡死”，本轮设备验收仍未通过。模拟器首帧用例通过不能替代此反馈。

进一步调整：显式调用 `MTKView.draw()` 管理每帧 drawable 生命周期，而非持续直接读取缓存 drawable；Core Image 图像构建、着色器编译和编码移至有界串行队列，主线程只采样/布局/编码背景与提交输入。旧渐隐按原线性采样生成有界浮点 alpha LUT，避免十七层嵌套合成扩张模糊着色器。验证增加重复 drawable 计数、播放中呈现进度及主线程响应检查，保持最多两个任务在途。真机是否消除卡死需重新安装确认，不能仅凭此调整宣称根因已证实。

后台或页面停用时同时作废排队中的 GPU 代次，防止已暂停的任务继续呈现或错误触发视频失败。回归通过暂停串行渲染队列，让真实调度器先提交任务，再停用页面、释放队列并恢复，检查旧帧不呈现且恢复代次仍能显示首帧。
