# 沉浸封面：背景暗度与过渡区域调整

## 2026-10-04：独立实时下层模糊，只渐弱半径

用户明确“淡出”是模糊效果本身的淡出，不是模糊图层的不透明度渐隐。本节替代此前半径和透明度一起渐变的实现。

- 模糊继续为独立原生平面，按当前实际 `UIView` 插入顺序和 `CALayer.zPosition` 逐次采样其下方所有可见兄弟平面，按从下至上合成后再统一变模糊。普通新增下层平面也参与，不仅限于背景/视频/倒影名称；自身及更高平面不会采样，避免模糊反馈或误处理上层内容。
- 向上 smoothstep 渐变只传入 Core Image 滤镜半径遮罩；删除相同梯度的图像透明度遮罩。默认不透明度为 1 时模糊输出没有额外 alpha mask，避免清晰原图通过第二层渐隐重新混入。顶部趋近零模糊，下方保持完整半径，仍不添加任何材质颜色。
- 手动调试“不透明度”和页面关闭转场仍保留，但仅为整层统一混合值，与纵向模糊梯度分离。实时半径、位置、尺寸、自由排序和用户已有数据均保留；媒体底部渐隐继续只作用于视频和倒影。
- 保留一个播放器、30Hz 实时采样、串行后台滤镜及最多一个在途任务。内容变化、隐藏、实际层级变化在下一采样更新，不要求重新配置或创建播放器。
- 新增真实 UIKit 像素回归：半模糊位置不残留来自透明度渐隐的清晰条纹；显式混合值在上下位置相同；额外兄弟平面在下方被模糊、上方保持清晰、移动层级后实时更新、隐藏/变色后没有旧图残留。保留实际视频/倒影、Metal 背景、实时强度及底部连续模糊回归。

## 2026-10-03：连续背景模糊与向上渐弱

本节替代下面“顶部固定为本层一半”的规则。底部背景始终模糊，模糊从视频底边向上延伸，逐步减弱至零；不再将底部背景模糊随媒体一起渐隐。

- 新增共享 `ImmersiveBackgroundBlurProfile`：视频底边是全强度起点，上方 smoothstep 过渡，底边固定在视口底部。正常宽度覆盖整个视口，包括窄视频左右两侧的背景。402×874pt、9:16 输入时，向上过渡从 Y=508.13pt 开始，在 Y=714.67pt 达到全强度并保持至 Y=874pt。
- Core Image 变模糊半径与可见覆盖读取同一份配置。下方背景及可见倒影保持所选高斯半径，上方逐步减弱；不添加材质底色、暗度或饱和度，也不创建第二播放器。仍只采样实际可见且位于模糊下方的内容。
- 最终底部渐隐只作用于顺序中位于它下方的视频与倒影，不作用于连续背景模糊。否则最下方会重新露出清晰背景，违反本次要求。原背景管线在沉浸模式中仍跳过自身模糊，由统一模糊完成，避免两次过滤。
- 没有已显示视频或调试关闭视频时，模糊区域改为全页背景，不保留隐藏视频的模糊副本。仍可通过原排序控件和各层开关调试真实可见平面。
- 保留所有临时存储值。“上沿偏移”只移动过渡上沿，“向上渐变长度”只改变向上延伸范围；全强度起点跟随实际视频底边，底边始终固定于屏幕底部。0–80pt 实时半径、横向宽度、透明度与自由层序继续可调。
- 新增真实 UIKit 像素回归：上沿保留条纹细节，视频底边以下及屏幕底部始终模糊；开关最终媒体渐隐不改变底部模糊；隐藏视频后顶部背景也完整模糊。补充几何测试检查上沿、全强度交界和固定底边。

验证：本地 15 项 Node 回归通过；本轮 UIKit/Metal 测试与两路 IPA 等待当前提交 CI。上一提交 `13d6db95` 的 435 项单元与 8 项 UI 均通过，仅作为历史结果，不替代本轮验证。实际设备的衔接观感、实时半径响应及性能仍待验收。

## 2026-10-03：无染色实时渐变模糊与强度更新

本节替代下方系统材质 blur / fractionComplete 路径，保留历史设备反馈。

- 去除 `.regular` 系统材质与冻结的效果动画，独立过渡只做 Core Image 高斯变模糊，不添加白色、黑色、饱和度或材质底色。背景暗度仍由原独立蒙层管理。
- 顶部半段使用固定 smoothstep 渐变：顶部无模糊、无覆盖，向下达到调试半径与覆盖强度；下半段维持。渐变绑定过渡层自身的局部坐标，不再用视频底边作终点。因此移动视频、倒影或整个过渡层时，顶部始终淡出。最终底部渐隐仍独立按用户层序作用。
- 原 0–80 存储数值保留，滑块现在直接控制 0–80pt 半径；按采样缩放转换为像素。每次参数、位置、层序与可见性更改淘汰旧结果；暂停视频时依然重新合成，无需重建播放器。
- 输入仅来自实时可见且位于模糊下方的原生平面：背景/暗度使用公开 hierarchy capture（含 Metal 视图），倒影使用当前已呈现图像和原遮罩，视频使用同一播放器的当前帧及实际等比矩形/透明度/渐隐。隐藏或位于模糊上方的视频不会留在合成中；不重复下载或创建第二播放器，也不重复生成倒影。
- 30Hz 显示调度、一个串行 Core Image worker、最多一个在途合成；忙时合并刷新，不累计任务。离开窗口/后台停止提交，关闭页面释放快照。非沉浸歌词引擎、用户背景值及历史回放修改不变。
- 回归新增：均匀色经过真实视图后 RGB 不被材质改变；弱→强→弱反复调整改变实际条纹细节；视频底边变化不影响同一过渡遮罩；实际 Metal drawable 在模糊后维持颜色。保留视频、倒影可见性与自由层序回归。

- 临时面板新增“层级顺序（最上层 → 最下层）”，复用歌词来源排序的 SwiftUI `ForEach.onMove` 与 `EditButton`。上移提高层级；六个组件均可排序，顺序独立持久化并随调试 JSON 导出。旧配置缺少顺序时采用原默认顺序，去重并补齐缺项。

- 渐变模糊改为公开 `UIVisualEffectView` 的实时 backdrop 采样，不再接收视频帧或显示独立的视频模糊图。只处理它下方实际可见的内容：关闭视频后不保留该视频的模糊副本，仍开启的下方倒影继续参与；视频和倒影都关闭后，模糊随当前背景变化；移到模糊上方的组件不参与采样。
- “实时模糊强度”仍使用原存储值 0–80，通过公开 `UIViewPropertyAnimator` 控制系统效果强弱，不将其宣称为可指定 pt 的高斯半径。效果透明度与向上渐隐合并到直接作用于 effect view 的 mask；模糊及其原生祖先保持 alpha=1，不再使用共同父层 mask。该约束来自 [Apple UIVisualEffectView 文档](https://developer.apple.com/documentation/uikit/uivisualeffectview/)。
- 底部渐隐在顺序中表示独立遮罩操作：只作用于其下方的视频、倒影和模糊，不使全页背景与暗度消失；移到渐隐上方的媒体不再受它影响。倒影保留原自身淡出，但没有额外模糊；模糊仍延长至屏幕底边，向上淡出。
- 非沉浸歌词路径保留原合成组、排版和动画。沉浸路径移除额外 SwiftUI 离屏合成组和祖先 clip mask；圆角由原生媒体容器自身的 bounds/cornerRadius 裁切处理，关闭转场的不透明度分别作用于画面组件和控件，live effect 的祖先始终保持 alpha=1。播放器仍只有一个，倒影继续由原有有界帧通道生成。
- 新增真实 AVPlayer 和实际 UIView 截图回归：切换可见层、重排实际顺序、移动渐隐、关闭视频与倒影后改变背景色；检查实际像素随背景更新、blur 不持有视频 bitmap，并以黑白条纹对照验证效果确实模糊而非仅显示背景色。配置验证覆盖旧值兼容、去重、缺项补齐、移动与导出。

验证状态：本地 15 项 Node 回归通过；Apple 原生回归、实际设备实时模糊效果及性能待新提交验证。`3005063a` 测试共 427 项，底部最终渐隐断言失败一项（8 项 UI 通过），该旧 SwiftUI 路径不作为本轮通过证据。

本节替代下面旧版层序与双向淡出的规则。`6f266f85` 设备反馈为开启倒影后模糊过渡不可见；该提交 Apple 回归也出现 3 个倒影接缝断言失败，8 项 UI 检查通过，不能标记解决。

从底到顶的 **4 个合成平面、6 个可调组件**：

1. 全页背景与黑色暗度蒙层：分别可调，位于所有媒体下方，只压暗背景。
2. 完整视频与倒影：同一媒体平面，倒影紧接视频底边；去掉倒影单独的高斯模糊及额外饱和度。仍然共用一个静音播放器。
3. 渐变模糊过渡：位于视频和倒影上方，从原过渡顶部一直延伸到屏幕底边；顶部透明、模糊弱，到视频底边达到全强度，向下维持不透明度与模糊，不再次淡出。输入由同一帧的视频和实际倒影映射合成，然后统一变模糊，避免只有视频底边颜色遮盖倒影。
4. 底部渐隐：最后应用于整个媒体组的独立透明度遮罩，向下露出背景；不再由 AVPlayerLayer 自身遮罩处理，不因开启倒影而移除。前景文字、控件和关闭横条位于这些效果之上，保持原布局。
