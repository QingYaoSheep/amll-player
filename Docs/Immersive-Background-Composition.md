# 沉浸封面：背景暗度与过渡区域调整

## 2026-10-03 当前实现：媒体上方模糊、屏幕底边延伸与临时调试

### 3005063a 设备反馈及原生合成修正

- 设备验证：开关倒影均看不到模糊；关闭完整视频后模糊可见，确认模糊已取得视频帧并生成画面，但与实际视频共同显示时被遮盖。`3005063a` 的设备验收仍失败，不能以声明层序正确替代实际合成。
- 视频、倒影、模糊改为一个 `ImmersiveArtworkMedia.Surface` 中的真实 UIKit 子视图。视频平面与倒影 zPosition=0，模糊 zPosition=1，最终渐隐放在这个共同父图层的 mask 上；避免分离 SwiftUI 托管与离屏遮罩影响实际视频层排序。
- 视频不透明度移到包裹 AVPlayerLayer 的独立平面，避免播放器首帧/缓冲更新覆盖调试透明度；禁用层仍保留一个播放器及当前帧来源。
- 新增带 2 秒无声音视频夹具的真实 AVPlayer/CADisplayLink 回归：验证首帧与模糊内容、共同原生父层、实际 zPosition、倒影切换、隐藏/恢复视频与最终 mask。此前静态 Core Image 合成不足以证明实际播放器层序，因此单独保留设备失败记录。新原生合成仍待 Apple 与设备验证。

本节替代下面旧版层序与双向淡出的规则。`6f266f85` 设备反馈为开启倒影后模糊过渡不可见；该提交 Apple 回归也出现 3 个倒影接缝断言失败，8 项 UI 检查通过，不能标记解决。

从底到顶的 **4 个合成平面、6 个可调组件**：

1. 全页背景与黑色暗度蒙层：分别可调，位于所有媒体下方，只压暗背景。
2. 完整视频与倒影：同一媒体平面，倒影紧接视频底边；去掉倒影单独的高斯模糊及额外饱和度。仍然共用一个静音播放器。
3. 渐变模糊过渡：位于视频和倒影上方，从原过渡顶部一直延伸到屏幕底边；顶部透明、模糊弱，到视频底边达到全强度，向下维持不透明度与模糊，不再次淡出。输入由同一帧的视频和实际倒影映射合成，然后统一变模糊，避免只有视频底边颜色遮盖倒影。
4. 底部渐隐：最后应用于整个媒体组的独立透明度遮罩，向下露出背景；不再由 AVPlayerLayer 自身遮罩处理，不因开启倒影而移除。前景文字、控件和关闭横条位于这些效果之上，保持原布局。

默认仍完整等比显示视频；402×874pt、9:16 输入时视频为 402×714.67pt，倒影从 Y=714.67pt 开始；模糊过渡 Y=508.13–874pt，宽 402pt、高 365.87pt。独立底部渐隐默认覆盖同一纵向范围。调试宽高围绕各层原中心缩放，位置为 pt 偏移。

临时面板入口：沉浸页右上调节按钮，或设置 → 沉浸封面层级调试（临时）。背景、暗度、视频、倒影、模糊、渐隐各有开关、X/Y、宽/高倍率及不透明度；模糊另有 0–80pt 半径；渐隐的透明度滑块表示遮罩强度。每层可重置，全部可重置，支持复制和分享 JSON。暗度未调节时沿用用户原背景暗度；倒影默认 0.32，其他画面层默认 1。

数值单独保存在 `AMLL.temporaryImmersiveLayerTuning.v1`，不修改歌词配置、时钟或音译。数值将由用户设备调试后固化，再删除临时入口与存储。帧分发保留一个最新帧，暂停时重新挂载、缩放或调节模糊也能重建；后台队列仍只有一个在途任务和一个最新待处理帧，旧代次不能回写。

本地 15 项 Node 回归通过；新增 Apple 变模糊、真实遮罩、倒影输入、最终渐隐及调试配置回归。Xcode 两路构建、实际设备观感与性能分别待验证，不将新层序接线视为设备验收通过。

## 2026-10-03 最新要求：中央最强、上下淡出、向下延伸

- 用户进一步明确：模糊程度与不透明度均在中间最强，向上、向下淡出；扩大向下的纵向长度。此要求替代上一版单向淡出与固定底边的规则。
- 保持原上边位置，下方延伸等长区域，使中央对准视频底边。横向仍与视频同宽。
- 遮罩两端透明、中央不透明，以平滑曲线连接；中央保留占总高度 12.5% 的最强区域，覆盖视频与背景的实际交界，避免量化后的细线。模糊半径中央最大 32pt，向两端降至零。
- 根据最新层级要求，从底到顶为：兜底色 → 背景及背景暗度 → 渐变模糊过渡 → 视频及其底部渐隐 → 可选倒影 → 前景信息与控件 → 关闭横条。模糊过渡已移到视频底部渐隐的下一层。
- 开启倒影时主视频仍关闭底部渐隐；关闭倒影恢复原渐隐。它不再借用模糊层的双向曲线。
- 延伸部分复制同一视频帧的底边颜色，保留原视频缩放和上方像素对应；不创建第二个播放器，仍使用有界串行后台处理。
- 402×874pt 视口、9:16 视频：视频底边 Y=714.67pt；过渡上边 Y=508.13pt，中央 Y=714.67pt，下边 Y=921.21pt，高 413.08pt、宽 402pt。视口外部分由页面边界裁掉。
- 状态：已接线待验证。更新真实遮罩、条纹细节与实际层序的合成图检查；新提交两路 IPA、Apple 回归和设备观感分别记录。前版失败结果保留，不能替代本轮验证。

## 前一版要求与实现（414cda31–678091b5）

用户确认这里的“宽度”指左右侧边从上到下的纵向长度，不是横向宽度。

- 暗度蒙层移入 `AMLLBackground`，只压暗背景；主视频、倒影、模糊过渡、静态封面及控件均位于其上方。
- 过渡层以视频底部 34% 渐隐区域为基准，顶部向下收回该区域高度的 15%，底边固定在视频底边。`414cda31` 最初仅缩短 5%；设备反馈仍需缩短并下移，本轮将顶部收回幅度增至 15%，底边不变。
- 取消原来左右 24–48pt 的外扩，以及视频底部以下 120–260pt 的延伸；横向宽度与视频相同，不做梯形收窄。
- 开启倒影时移除主视频底部渐隐遮罩，关闭倒影时恢复；模糊过渡仍保留。最大 32pt 变模糊、倒影高度与 0.32 强度保持现有值；仍复用同一个静音播放器的帧输出。
- 模糊过渡层的透明度从底部到顶部逐渐降低：底部 1、顶部 0。主视频遮罩保持原有向下淡出，不与模糊层共用方向。模糊强度仍从顶部 0 增加到底部 32pt。
- 不调整歌词、计时、音译、字号、前景控件布局及显示开关。

402×874pt 视口中的 9:16 视频：视频为 402×714.67pt；视频渐隐从 Y=471.68pt 开始；新过渡从 Y=508.13pt 开始，高 206.54pt、宽 402pt，底边 Y=714.67pt，与倒影起点一致。相对 `414cda31`，上边再下移约 24.30pt。

当前层序从底到顶为：兜底色 → 背景及其内部暗度 → 视频 → 可选倒影 → 缩短后的渐变模糊过渡 → 前景信息与控件 → 关闭横条。此前的接缝修复历史保留在 [倒影接缝记录](Immersive-Reflection-Seam.md)。
