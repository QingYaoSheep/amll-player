# 歌词页统一转场

实施基线：`9f7aef4a`。本次仅调整页面呈现，不修改歌词运动引擎、时间轴、逐字、run、HDR、混色及音译算法。

## 接口与行为

- 两个页面使用 `LyricsPagePresentationCoordinator` 处理显隐及延迟退场；过期完成回调不能关闭重新打开的画布。
- 内容使用 200ms `(0.23,1,0.32,1)`。根据首版真机“封面缩放生硬”的反馈，几何改为复用现有 `response=0.32 / dampingFraction=0.9` 弹簧，快速反向操作沿当前呈现值接续。
- 追加翻译／音译开关淡化：使用同样 200ms UI 曲线，退出时保留附加文字槽位，淡出完成后收起；普通与沉浸、独立音译共用。清晰 SDR 附加文字使用可见性遮罩；模糊像素仅在切换时后台拆分正文、翻译和音译贡献，各自执行透明度动画，避免残留光晕、误淡化正文和交替开关重启动画。新模糊结果准备完成前不发布包含完整附加文字的纹理。HDR 正文和逐字遮罩保持原路径；不创建动画循环或逐帧位图。
- 手机显隐时，紧凑与完整歌曲信息共享位置匹配；进度和控制区随之收起。兼容页底部控件保留在外壳中滑出，不通过删除视图打断转场。
- 原生画布始终挂载；隐藏后取消交互、辅助功能曝光和持续绘制，恢复读取最新播放状态。原来验证“隐藏后创建新画布”的测试改为验证保留身份，并保留音频落点、逐字时间和未填满断言。
- 原生媒体实例保持稳定，常规方形与沉浸布局共用一个播放器。相同资源普通配置刷新复用就绪资源；明确重新加载仍更换请求代次。
- 背景也只有一个原生宿主，普通/沉浸切换更新同一 Mesh 实例的混色策略，不同时保留第二份背景。退出把手的命中高度固定为 44pt，隐藏页的菜单不参与辅助功能匹配。
- 视频、倒影、渐隐及模糊使用同一布局事务，实时模糊读取呈现层几何。停止状态不增加显示调度器。
- 切歌立即显示新信息和可用静态封面；仅封面和信息转场。旧媒体最多保留一帧，视频帧只在资源替换时后台转换，过期转换拒绝提交。
- 快照准备期间保留旧原生画面；最长 200ms，超时直接应用新画面，不允许迟到旧帧覆盖。准备与已显示淡出的代号独立；取消准备回到当前资源时，按原截止时间恢复淡出并清理。
- 进入/退出延续系统 Zoom。兼容页面同样禁用重复的自定义下拉手势；非 Zoom 路径使用既有弹簧回弹。减少动态效果不启用页内几何动画。

## 回归边界

1. 协调状态：显示/隐藏、反向打断、过期退场、无变化快照、默认隐藏。
2. 原生媒体：真实窗口的中间位置与反向终点、同一播放器、迟到首帧、资源替换和缓存切换。
3. 生产画布：连续模式切换不改变文档和 seek 代次；隐藏后确认 seek、再次显示正确同步。
4. 原功能：16.4/advance/26.4/27/AMLL、独立音译、HDR/Plus Lighter、模糊等级以及点击返回弹簧。

Xcode 27 CI 的既有失败单独记录，不删除或放宽原断言。只有完整回归通过才产出测试后 IPA。iPhone 16 Pro/iPad/iOS 18 的视觉、交互取消、温度及十五分钟资源测量必须单独记录，构建通过不代表设备验收。
