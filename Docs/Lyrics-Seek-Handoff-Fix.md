# 点击歌词跳转与弹簧交接修复

## 范围

两项故障分别验证：网易云点击歌词后的偶发进度错位；各来源点击歌词后的弹簧动画缺失。录屏仅证明第二项。用户确认录屏来源为 Apple Music，提前滚动为 0.3 秒。

## 证据与原因

- 按真实帧时间检查 AMLL 录屏：2.775 → 2.808333 秒出现直接位置跳变，随后 2.855 → 2.871667 秒再次跳到确认位置。Apple Music 的对应点击片段 1.988333–2.138333 秒包含连续运动帧。两段视频按点击事件对照，不比较相同录像秒数或不同字体的像素亮度。
- 真实 AMLLFrameEngine 回归在 60/120Hz 与 37ms 帧间隔下复现位置直接到达终点；原因是 seek 的计时重置同时强制设置了最终位置。
- 请求发出先于播放器新进度到达。旧代码先退出浏览回到旧歌曲位置，再在进度确认时重新定位。上滑浏览场景的最小回归再次复现。
- 实际 NetEasePlayback 与可控制完成回调的 AVPlayer 回归：未完成 seek 时 refresh 发布临时解码时间；AVFoundation 返回 finished=false 时仍增加成功代次。两个用例出现三个断言失败：[原实现测试](https://github.com/QingYaoSheep/amll-player/actions/runs/36985751548)。

## 修复

- 未确认的 seek 保留当前浏览呈现，不先返回旧位置；确认后清理旧填充/HDR 保持和视觉焦点，真实计时立即重新锚定。
- 空间目标使用现有弹簧，从当前呈现位置接续；初次布局、尺寸重置和减少动态效果保留立即定位。关闭弹簧沿用原缓动。
- 网易云 seek 期间提交一次冻结的真实时间锚点，停止旧时钟插值；阻止周期采样发布临时解码进度。完成后将实际落点与成功代次一次性发布。
- 检查 AVFoundation 完成结果、请求代次与歌曲代次。失败、切源、暂停、中断、删队列当前项及切歌清理旧请求，不确认过期结果。
- 不修改真实歌词时间、offset、提前滚动、独立音译 TTML、字号、28% 定位或弹簧参数。

- 永久回归覆盖 60/120Hz 与不规则帧间隔、提前滚动 0/0.3/1 秒、正反 seek、真实画布、回播遮罩、offset、弹簧关闭、减少动态效果、实际落点、失败及迟到结果。
