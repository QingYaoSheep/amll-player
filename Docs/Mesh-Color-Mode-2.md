# Mesh网格（取色模式2）

在“歌词外观 → 背景模式”增加独立选项，不自动切换已有背景选择。

| 封面预处理 | 原 Mesh 网格 | Mesh网格（取色模式2） |
|---|---|---|
| 缩小尺寸 | 32×32 像素 | 64×64 像素 |
| 对比度、饱和度及亮度矩阵 | 保留原处理 | 跳过，保留封面颜色 |
| 方框均值模糊 | 四轮 | 两轮 |

两个选项复用同一 Mesh 上下文、网格预设/随机生成、旋转采样、暗角、切歌渐变、显示调度及辅助功能回退。切换取色模式只重建最新封面的颜色纹理，不重新建立网格或归零动画相位。

复用原背景模糊滑块及其半径换算；零模糊跳过均值滤波。页面背景暗度、着色器暗角及沉浸页关闭背景自身模糊的规则保持原状。“保留原始颜色”限定在封面预处理阶段。

## 验证状态

- 新增真实 PNG → Metal 纹理回归：64×64 尺寸、恒色封面原色保持、两轮均值滤波的条纹像素、零模糊，以及原模式 32×32 与颜色矩阵。
- 新增背景模式持久化、其他外观参数保留及沉浸模糊策略回归。
- Windows 没有 Swift/Xcode；Apple 编译与自动测试通过现有 Xcode 27 两路工作流执行。真机颜色观感、切换连续性与性能待验收。
