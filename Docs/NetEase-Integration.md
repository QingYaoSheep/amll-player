## 交付约定与架构

新增“设置 → 登录 → 登录到网易云音乐”。Swift 直接访问社区接口；不增加服务端、代理、解锁服务或应用内 JavaScript。使用固定公开协议作为互操作参考，不宣传官方授权 SDK。

复用 MusicSessionProviding、MusicCatalogProviding、MusicLibraryMutating 和 MusicPlaybackProviding；MusicServiceID 增加 netease。服务、账号连接上下文和请求代次隔离异步结果。旧用户来源不变，Spotify 与 Apple Music 仍保持各自控制路径。

扫码为主：生成、轮询、有效期、刷新和取消。Cookie 为主动粘贴的备用入口，验证成功后存 Keychain，失败保留原登录；不读取剪贴板或写入日志。退出清除会话/私人目录并暂停音频。登录没有自动切源。

主页各区独立请求与真实空态，最近播放来自服务端记录；不声称跨设备本机历史。搜索歌曲/专辑/艺人/歌单，300ms 防抖、建议及本地历史。歌单以完整 trackIds 顺序分批取详情，保留重复歌曲和不可用占位，按条目位置起播；不以第一页替代完整队列。公开目录在未连接时仍可浏览，私人接口和播放要求登录。

歌单编辑权限来自服务端 creator 与特殊歌单类型。收藏/取消收藏、创建、修改名称/描述、追加/移除和删除后核对服务端状态；创建或追加超时不盲目重复。删除需确认。歌单排序接口尚未验证，不开放；本地播放队列可排序。

原生歌曲播放使用 AVPlayer，前台/后台每250ms采样真实时间供 PlayerClock 和歌词插值；缓冲/暂停不推进歌词。进度约5秒保存，后台、暂停和切源立即保存。账号队列重启恢复为暂停，不缓存临时音源URL；播放地址失败有界重取，自动队列只跳过明确不可用/无权限/试听歌曲。随机顺序保存，上一首与循环保留条目身份。

集中 MusicAudioSession：网易云主动播放使用 playback；封面视频只申请允许混音的 ambient，歌曲拥有会话时不得覆盖。仅网易云主动本地播放注册歌曲级 Now Playing 和锁屏命令；切源暂停并释放控制，不启动其他来源。电话、耳机断开及音频服务重置保持暂停，不擅自恢复播放。启用后台 audio。

标准、高品质、无损，默认高品质；修改从下一首生效，当前歌曲需明确重新起播。展示服务返回的实际音质、降级原因及试听/无版权错误。音源和封面 CDN 不携带账号 Cookie。

网易云歌曲ID直接连接现有歌词查询；保留三源回退、人工匹配、offset、独立音译 TTML、HDR、提前滚动和浏览焦点。原文、计时及排版引擎不因接入而改写。

明确排除：离线下载、云盘上传、MV、播客、评论。音乐权限不可用时显示真实错误，不解锁或伪造结果。

## 自动与设备验收

自动覆盖 WEAPI 独立向量、Cookie/主机约束、失败导入保留、账号更换、QR迟到取消、有序分页/重复/不可用占位、跨查询游标、音源权限/试听/HTTPS、所有权和队列恢复。Spotify/Apple Music 及现有歌词用例继续运行。

设备必须验证：扫码允许/过期/取消、Cookie失效/换账号；免费/会员/试听/无版权；弱网/缓冲/URL过期/音质；后台锁屏/耳机/AirPlay/切源/重启；封面并发不打断歌曲；正反seek、回播/音译/HDR；收藏、写入失败/超时核对及只读歌单。15分钟资源有界性单独测量。

实际闭环门槛：登录 → 歌单/搜索 → 选歌播放 → 后台/锁屏 → 歌词同步 → 收藏/歌单修改。Windows检查、模拟服务和CI编译均不代替真实授权。两路IPA可重签；各自提交、结果与SHA-256在构建产物清单记录。
