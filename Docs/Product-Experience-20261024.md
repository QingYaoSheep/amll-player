# 非歌词页面体验改造 · 2026-10-24

## 范围

固定实现基线 `9707dd80`。改造主页、音乐库、搜索、歌手／专辑／歌单详情与设置分组；沿用 Spotify、Apple Music、网易云现有目录、登录、播放、权限与分页接口。此轮不改歌词页面、画布、HDR、音译、时间轴或封面合成。

## 页面与交互

- **主页：**横向封面卡片及三首歌曲一组的浏览架构，保留下一张露出以提示滚动；按卡片对齐停靠。大字体歌曲列改自然高度，避免固定高度裁切。分区独立加载与重试，刷新保留已有数据。
- **音乐库与搜索：**统一44pt分类胶囊；歌单、专辑与歌手共用自适应网格。综合搜索、300ms防抖、建议、历史、旧请求取消维持原实现；返回详情保留输入，切换来源清空旧来源导航。
- **歌手：**圆形头像、可播放的热门歌曲、专辑网格、可展开介绍。网易云复用既有歌手响应中的 hotSongs／briefDesc，无额外请求；其他服务只显示真实提供的数据，不编造介绍或排行。
- **歌单／专辑：**封面、名称、艺人链接、歌曲数／发行时间、完整上下文播放与服务支持的随机播放；介绍可展开，不用字符数猜测是否会换行。列表显示原始位置、时长，保留重复歌曲和完整分页上下文。
- **失败恢复：**首次 Spotify 详情权限失败仍保留官方打开入口，不能只有技术错误。分享、收藏及歌单编辑复用原权限限制与迟到结果保护。
- **设置：**音乐、个性化、存储、支持分组；开发诊断进一步收纳，常用账号与外观入口保持可达。
- **图片：**按显示尺寸后台缩略解码，32MiB LRU预算；支持现有远程HTTPS及应用本地图片，不因同一封面的显示尺寸变化先闪回占位图。

## 动效约定

| 触发 | 目的 | 实现 |
|---|---|---|
| 按住卡片／按钮 | 立即确认触碰，松手或移出可取消 | 当前项缩放至0.97、透明度0.78，120ms ease-out；减少动态效果仅保留透明度反馈 |
| 封面就绪、分区数据出现、筛选切换 | 降低替换突变 | 200ms ease-out；不做持续运动、逐项延迟入场或滚动显现 |
| 进入／退出详情 | 保留空间方向与可中断返回手势 | 系统 NavigationStack 转场，不叠加自制动画 |

布局不依赖人工动画等待，操作不锁定输入；歌词页原动效不受本轮样式影响。
