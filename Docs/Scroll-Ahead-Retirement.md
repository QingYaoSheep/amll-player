# 提前滚动时的同步退焦修复

## 行为

顺序歌词因“提前滚动”设置开始自动上移时，旧句从同一运动启动事件开始缩小、退亮、模糊及 HDR 渐退，不等待真实句尾或下一句到达焦点。保留正文 1.00 → 0.97、现有弹簧及 0.4 秒亮度／模糊过渡。

视觉退出不改写真实逐字时间或独立音译 TTML：尚未唱完的部分不提前填满。真实时间重叠的声部继续按自己的演唱资格保持外观；主歌词与背景人声分别判断。手动浏览不触发提前退焦，继续使用既有无模糊规则。seek 清除旧退焦，暂停可完成已经启动的空间／外观过渡。

## 根因与修复

- 原退焦调度必须等待 `mainCompleted`／`backgroundCompleted`，提前滚动在实际句尾前启动时无法创建过渡。
- 每帧的真实演唱判断会恢复保留焦点。现改为已有退焦状态时不重新保留，真实 `Row.active` 和逐字时钟仍保持。
- 旧视觉焦点索引在下一行错峰启动前短暂保留。已有退焦的行不再通过该索引取得“准备”外观，防止缩放延迟。
- 顺序关系依据保留的原始结束时间与接棒组原始开始时间判断，不使用提前后的显示时间冒充真实声部重叠。
- 复用既有自身上移绝对启动时间和跨帧剩余时间消费；缩放、SDR／HDR 有效亮度及模糊同帧启动，不新增动画循环或设置。
- 隐藏已播放行继续以真实演唱资格为边界；提前退焦不将正在唱的旧句提前隐藏。实际播放时钟跨句尾向后校正时恢复逐字演唱，不重新消费已经启动的上移事件。
- 提前退出仅允许由该行自身的上移启动事件触发；后来到期的接棒焦点确认只释放已完成的行，不能再次让校正后恢复演唱的行提前退出。回归包含跨过该错峰 deadline 的后续帧。
- 上移判断读取实际呈现位置：弹簧模式读弹簧位置，无弹簧模式读位置过渡值；减少动态效果在直接定位前采样旧位置，按既有辅助功能规则立即完成退焦。
